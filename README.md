# PMDC Motor Modeling and Simulation

This repository presents the mathematical and physical modeling of a **Permanent Magnet DC (PMDC) Motor** using **MATLAB Simulink** and **Simscape**. The project analyzes the dynamic behavior of the motor by comparing equation-based and physics-based simulation approaches.

---

## Project Overview

A Permanent Magnet DC (PMDC) motor is widely used in low-power electromechanical systems due to its simple structure, high efficiency, and ease of speed control. Unlike separately excited DC motors, the magnetic flux is provided by permanent magnets, eliminating the need for a field winding.

This project implements and compares two different modeling techniques:

- **Equation-based modeling** using Simulink block diagrams
- **Physical component-based modeling** using Simscape

Both models are simulated under identical operating conditions to evaluate their dynamic responses.

---

## Theoretical Background

The PMDC motor is modeled under the assumption of a constant magnetic flux generated by permanent magnets.

### Main Characteristics

- Constant magnetic flux (Φ = constant)
- Back electromotive force (Back EMF) proportional to angular speed
- Electromagnetic torque proportional to armature current
- Simple control structure
- High starting current due to zero initial Back EMF

## Modeling Approaches

### 1. Simulink Model

The Simulink implementation directly represents the mathematical equations governing the electrical and mechanical dynamics of the PMDC motor.

The model includes:

- Armature circuit dynamics
- Mechanical rotational dynamics
- Electromagnetic torque generation
- Back EMF feedback

This approach clearly illustrates the interaction between the electrical and mechanical subsystems.

### 2. Simscape Model

The Simscape implementation models the motor using physical components instead of explicit differential equations.

Components used include:

- DC Voltage Source
- Resistor
- Inductor
- Rotational Inertia
- Rotational Damper
- Rotational Electromechanical Converter

This method provides a more realistic representation of energy conversion and physical interactions.

## Results

The simulations show consistent behavior for both implementations.

Observed characteristics include:

- High armature current at startup due to zero Back EMF
- Increasing motor speed as the motor accelerates
- Decreasing armature current as steady-state is reached
- Electromagnetic torque following the armature current profile
- Nearly identical dynamic responses from both modeling approaches
